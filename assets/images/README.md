# Stillbow image assets

Generated with the built-in imagegen tool. Both images are now loaded by main.gd. The archer alpha bounds (threshold 0.1) are cropped at runtime and rendered at 76 pixels tall with mipmaps, smoothly rotated toward the target. The arena floor is cropped to retain its original aspect ratio; wall strips restore the top and bottom perimeter. A subtle dark overlay improves projectile readability.

- `archer-v1.png`: original overhead teal hooded archer with a gold bow, transparent PNG.
- `arena-v1.png`: portrait overhead navy stone arena, clear floor and perimeter walls, no UI or characters.
